# REDROX Industries - Official Website

![REDROX - The Backbone of Better Buildings](images/logo-combined.png)

> **Live Website:** [redroxindustries.com](https://redroxindustries.com)

This repository contains the source code for the official website of **REDROX Industries Pvt Ltd.**

## 🧱 About REDROX

REDROX is an innovative, clean-tech construction startup solving the global textile waste crisis. We manufacture sustainable, high-strength interlocking infrastructure blocks using shredded waste cloth fibers and 110-ton hydraulic compression technology. 

Our blocks deliver:

* **Strength:** 4–5× greater load-bearing capacity than conventional clay bricks.
* **Speed:** Reduces construction timelines from two years to about six months through dry-stack interlocking.
* **Comfort:** Keeps indoor temperatures up to 10°C cooler and reduces sound, echo, and vibration.
* **Sustainability:** Reduces water consumption by up to 70% while delivering significant cement savings.

## 💬 REDROX Assistant

The website includes a responsive product chatbot adapted for this static site. It answers questions using only information published in this repository.

Supported topics include:

* Product strength and 110-ton hydraulic compression
* Dry-stack construction speed
* Textile-waste reuse and resource savings
* Thermal, acoustic, seismic, and crack resistance
* Testing-report details
* Partnership and contact information

The assistant runs entirely in the browser. It does not require an AI API key, external chatbot service, or backend endpoint. Project-specific pricing and unpublished information are not invented; visitors are directed to the partnership form instead.

## 💻 Tech Stack

This is a lightweight, high-performance static website built for speed and global accessibility.

* **Frontend:** HTML5, CSS3, JavaScript
* **Form Handling:** [Formspree](https://formspree.io/) (Serverless form submissions)
* **Hosting & CI/CD:** [Netlify](https://www.netlify.com/) (Automated deployments from the `main` branch)
